Python gives each resource with a method a factory in the Workflow package too, and both factories take the definition of a resource with `@nexus.definition`. `@nexus.flatten-in-api param="..." fields="..." [keep=true]` on a resource makes a Python factory take fields of one constructor parameter. A Python resource with one required field of a non-generic proto-backed record, and no other required field, passes as that record, so a `Stream` crosses the targets as its `StreamRef`.
